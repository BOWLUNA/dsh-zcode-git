# 测试

[English](README.md) | 中文

唯一入口：

```bash
node test/run.mjs
```

它会跑本目录下每一个 `*.test.js`，同时打印原始的 `# tests N` 计数
（`tools/verify-doc-numbers.mjs` 读的就是它）与一行汇总，并在任何失败时以非零码退出。
套件清单是**读目录**得出来的，不是写死在这里 —— 否则一个存在却从未被运行的套件，
会在所有地方被静默跳过。

## 分层，以及只有每一层能抓到什么

| 文件 | 层 | 只有这一层能看见的失败 |
| --- | --- | --- |
| `parse.test.js` | 纯解析器 | 含空格的路径被切成两条记录 |
| `validate.test.js` | 纯校验 | `..\..\x` 从只查 `/` 的穿越检查下溜过去 |
| `exec.test.js` | spawn 规格 | argv 数组又悄悄变回了命令字符串 |
| `tools.test.js` | 工具行为 | 渲染器读了 `execute` 从未返回的字段 |
| `schema.test.js` | schema | 某个 harness 版本会拒绝的关键字 |
| `e2e.test.js` | 真实 git | 一个关于 git 格式的错误假设 |

## 端到端为什么要单独一层

`test/e2e.test.js` 会在系统临时目录下建真实仓库、跑真实的 `git` 二进制，结束后删掉。
它比其余层慢，而这个代价是值得的：`git branch --format` 里 `%1f` / `%x1f` 转义语法
那个错误，照着同一个错误假设写的单元测试**完全看不见**，而在生产里它是**静默失败** ——
git 原样输出字面量、任何字段都切不开、所有分支被过滤掉，且没有任何报错。

它需要 `PATH` 上有一个 `git`。git 不存在时这些用例会**失败而不是跳过**，
因为一个被静默跳过的端到端层，比没有这一层更糟。
